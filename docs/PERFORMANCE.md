## 3. 이번 개선이 성능에 준 영향 (코드 근거)

- 제거: 화면 전체 눈 내리는 캔버스(상시 애니메이션), 카드마다 `backdrop-filter: blur(22px)`, 포인터를 따라가는 하이라이트, 상태 점의 상시 숨쉬기, 차트 선 drop-shadow 필터.
- 남긴 움직임: 상태가 바뀌는 순간의 파문 1회, 방문자 입장·퇴장 1회, 새 수집 도착 표시 1회. `prefers-reduced-motion`이면 모두 끔.
- 폴링: LIVE 화면은 3초 → 10초 간격 확인. 원본 호출은 수집 주기(30초)마다 한 번.
- 개선 전후의 프레임 시간·CPU는 측정하지 않았다. 위 항목은 제거한 작업 목록이지 측정 결과가 아니다.

## 4. 게임 서버 부하 (원본 패치)

- `/metrics`는 Durable Object에서 5초 캐시. 대시보드 기본 주기(30초)면 분당 2회 호출.
- 인증 실패 요청은 Worker 진입점에서 끝나 DO를 깨우지 않는다.
- 추가 계측은 메시지 송신마다 정수 1 증가 한 번.
- 원본 전체 테스트 600/600 통과(부하 시험 `test:load`는 이번에 실행하지 않음).
